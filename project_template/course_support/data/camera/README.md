# Учебная камера

Авторские синтетические изображения, созданные для курса Анатолия Дуркина. Разрешены использование, изменение и распространение с указанием источника курса. Не фотографии реальной камеры. Генератор в приватных методических материалах: tools/build_camera_data.py.

12 кадров 640×480, доска 10×7 клеток и 9×6 внутренних углов, сторона клетки 0.025 м. Разные наклоны и расстояния; модель pinhole с радиальной дисторсией. model.json содержит истинные параметры генератора только для сравнения; оценка строится по обнаруженным углам. detected_corners.npz — запасные результаты детектора с этих кадров, не идеальные точки. reference_fit.npz — калибровка по этим измерениям для резерва. Небольшая ошибка на синтетике не гарантирует качество на реальной камере.

teaching_photo.jpg — синтетическая картинка с демонстрационными EXIF (Make/Model/Software), без GPS и настоящих персональных сведений. Пустые EXIF у других PNG нормальны.

Описание алгоритма: https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html
