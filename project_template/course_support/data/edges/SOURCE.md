# Синтетические изображения блока 4

Созданы для практики А. А. Дуркина; учебное использование и публикация результатов разрешены с указанием источника. Людей, реальных объектов и персональных данных нет. Генератор сохранён у преподавателя. scene.png — фигуры на фоне и нормальный шум sigma=7, seed=42; края зависят от контраста и порогов. binary.png — две фигуры, отверстие и маленькая точка для морфологии. measure.png — прямоугольники в одной плоскости при масштабе 2 пикселя/мм. Опорная ширина 100 пикселей = 50 мм, исследуемая — 160 пикселей = 80 мм. В measurement.json указаны полуоткрытые границы, ширина=x1_exclusive−x0. Это учебная проверка масштаба, не метрологическая аттестация настоящей камеры.

Иллюстрации внутри notebooks — сохранённые результаты указанных операций, не результат запуска студента. При работе без OpenCV можно разбирать их и выполнять самостоятельные эксперименты на NumPy и Matplotlib. Собственный запуск библиотеки остаётся отдельным действием.
