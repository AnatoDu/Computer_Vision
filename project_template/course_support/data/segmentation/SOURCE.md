# Источники изображений блока 6

coffee.npy: фотография Rachel Michetti, Pikolo Espresso Bar, CC0. Копия skimage.data.coffee,
400×600×3 uint8, сохранена без изменения пикселей. coins.npy: коллекция Brooklyn Museum,
скопировано из skimage.data.coins,303×384 uint8. Документация сообщает «No known copyright restrictions»;
это формулировка источника, не наша новая лицензия. Источник обоих:
https://scikit-image.org/docs/stable/api/skimage.data.html (coffee, coins).
Фото поставляются локально; студенту scikit-image и скачивание не нужны. Пример на чашке
не имеет эталонной разметки объекта, поэтому количественную точность на нём не объявляем.

touching.npz: собственные два касающихся круга на поле 240×360. mask — объединённый передний план,
markers — две предоставленные точки; reference — подготовленная иллюстрация watershed от отрицательного
расстояния до фона (SciPy distance_transform_edt + scikit-image watershed). Это вычисленный при подготовке
результат, а не запуск алгоритма студентом. Геометрия и число объектов заданы при создании опыта.

covers.npz: собственные синтетические обложки 96×144. Класс 0 — цветовые половины сверху/снизу,
класс 1 — слева/справа. Два изменения яркости каждого объекта остаются в одном split.
train:6 объектов/12 картинок; validation:4/8; test:4/8. Независимость здесь относится к ID генератора,
а не доказывает способность распознавать реальные книги. Это контролируемый опыт выбора признака.
Синтетические материалы разрешено использовать и изменять с указанием курса.
