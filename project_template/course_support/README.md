# Учебная поддержка Computer Vision

Источник: https://github.com/AnatoDu/Computer_Vision — старший преподаватель Дуркин Анатолий Альбертович.
Версия и SHA-256 файлов — manifest.json; это идентификатор локальной выдачи, не обещание опубликованного коммита.

checks.py — обратная связь для упражнений; cvtools.py — чтение и показ картинок.
video.py — служебный обход связных областей бинарной маски в блоке 07, не готовый трекер.
Это готовые материалы преподавателя, не самостоятельная разработка студента.
Данные занятий находятся в data; происхождение и условия описаны в data/README.md.
Собственные данные держите отдельно в data проекта.

Передавайте эту папку вместе с учебными тетрадями, в том числе при сдаче архивом. Если публикуете работу на GitHub, включите её в свою копию; сам GitHub необязателен. Для учебной выдачи преподавателем предусмотрено такое копирование; отдельная универсальная лицензия исходного репозитория здесь не устанавливается.
Проверки работают локально, ничего не отправляют и не выставляют официальную оценку.
После новой выдачи заменяйте поддержку целиком, сделав резервную копию своего проекта. Не заменяйте workbooks с ответами.
Проект в notebooks должен обходиться без учебных checks.

В репозитории курса эта папка — источник. В личном проекте — поставленный снимок. Импорты одинаковые: `from course_support.checks import check`; путь к учебным данным — `from course_support import DATA_DIR`.

Блок 08 использует локальное фото coffee из data/segmentation и синтетические covers, условия описаны там же.
Рамки чашки/ложки в 08 — ручные учебные примеры, не официальный эталон фотографии.
Проверки 08 работают без OpenCV. Учебный AP в notebook не заменяет COCO evaluator.

Блок 09: data/digits содержит реальные бинарные цифры UCI 32×32, CC BY 4.0, авторы E. Alpaydin/C. Kaynak.
Оригинальные части tra/cv/windep сохранены; описание и SHA-256 рядом. Validation не объявлена независимой
по почеркам от train; независимость итогового test основана на описании источника. Checks 09 не требуют OpenCV/sklearn.

Блок 10: data/digits/mlp_reference.npz — реально обученные на CPU веса MLP и журнал 12 эпох;
параметры, версии и контрольные суммы — MLP_RUN.json. Это предоставленный запуск, не работа студента.
Основная 10.1 и все новые checks требуют только NumPy. 10.2 обучает при доступном PyTorch или
явно переключается на анализ весов в NumPy. Test для настройки этого блока не используется.
