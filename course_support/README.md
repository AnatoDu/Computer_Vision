# Учебная поддержка Computer Vision

Источник: https://github.com/AnatoDu/Computer_Vision — старший преподаватель Дуркин Анатолий Альбертович.
Версия и SHA-256 файлов — manifest.json; это идентификатор локальной выдачи, не обещание опубликованного коммита.

checks.py — обратная связь для упражнений; cvtools.py — чтение и показ картинок.
Это готовые материалы преподавателя, не самостоятельная разработка студента.
Данные занятий находятся в data; происхождение и условия описаны в data/README.md.
Собственные данные держите отдельно в data проекта.

Сохраните эту папку в своём GitHub вместе с работой. Для учебной выдачи преподавателем предусмотрено такое копирование; отдельная универсальная лицензия исходного репозитория здесь не устанавливается.
Проверки работают локально, ничего не отправляют и не выставляют официальную оценку.
После новой выдачи заменяйте поддержку целиком, сделав резервную копию своего проекта. Не заменяйте workbooks с ответами.
Проект в notebooks должен обходиться без учебных checks.

В репозитории курса эта папка — источник. В личном проекте — поставленный снимок. Импорты одинаковые: `from course_support.checks import check`; путь к учебным данным — `from course_support import DATA_DIR`.
