# Optical Recognition of Handwritten Digits — 32×32

E. Alpaydin, C. Kaynak (1998), UCI Machine Learning Repository, DOI 10.24432/C50P49.
https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits
Лицензия страницы UCI: CC BY 4.0 https://creativecommons.org/licenses/by/4.0/ .
Это реальные рукописные цифры, не генерация курса. Исходные нормализованные бинарные изображения
32×32 преобразованы из текстового формата в uint8 NPZ без изменения пикселей или меток.
Сведения авторов сохранены в optdigits-original-description.txt; контрольные суммы — snapshot.json.

Используются оригинальные части tra (1934), cv (946), windep (1797). Дополнительная wdep не используется.
В описании авторов test windep составлен из других 13 писавших людей, чем обучающая часть (30 людей).
Validation cv не объявляется независимой по авторам письма от train. Поимённые writer_id в поставляемом
формате отсутствуют, самостоятельно проверить эти группы по строкам нельзя; опираемся на описание источника.
Именно поэтому на собственных данных в 09.1 сохраняем group_id до разбиения. Не подменять тест случайной
нарезкой всех цифр. Для CNN далее сохранять эту же задачу и исходную test-часть.

Учебный эксперимент отличается от распознавания произвольного фото: цифры уже выделены, центрированы,
имеют одинаковый размер, фон и известный набор классов. Отдельно измеряем ограничение такого упрощения.

## Предоставленная MLP для блока 10

mlp_reference.npz содержит веса двух Linear и историю фактически выполненного CPU-обучения
на исходной tra с выбором эпохи по cv. MLP_RUN.json фиксирует параметры, версии и SHA-256.
Ни исходный test, ни ответы студентов при обучении/выборе эпохи не использовались.
Создано для учебного комплекта; разрешено использовать в учебных проектах с указанием, что веса
предоставлены преподавателем, а данные происходят из UCI (атрибуция выше). Не выдавать за своё обучение.
Воспроизведение: основной код 10.2 с PyTorch; данные уже локальные, no pickle, никаких загрузок моделей из сети.
