# Учебные изображения для особых точек и геометрии

Оригинальные синтетические растры, созданные для курса. Не фотографии; людей, документов
с персональными данными, чужих логотипов и результатов распознавания нет.
Разрешено использовать и изменять с указанием курса как источника.

`card.npy`: серое изображение120×180, float, яркость0…1. Светлая карточка с простыми фигурами.
`document.npy`: прямоугольный учебный лист100×140; полоски изображают строки, но не текст.
Фотографию с перспективой тетрадь05.2 генерирует сама по известному преобразованию.
Это контролируемый опыт: геометрия известна, реальные тени, линза и шум камеры не моделируются.
Сдвиги/повороты в05.1 создаются кодом, не выдаются за новый реальный снимок.
Координаты геометрии: (x,y)=(столбец,строка). Индексы массива: image[y,x].
Никаких загрузок из интернета; np.load(...,allow_pickle=False).
