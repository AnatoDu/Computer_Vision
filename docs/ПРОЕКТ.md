# Семестровый проект: собственный результат

Индивидуальный проект растёт по этапам ЛР4–6; ЛР1–3 — учебные упражнения. Итог — самостоятельная папка проекта: понятная задача, доступные данные, код, честное сравнение и ограничения. GitHub и Git необязательны; сдача архивом и ссылкой равноправна. При выборе приватного репозитория предоставьте преподавателю доступ. Рабочие тетради — учебный архив, проект в notebooks — ваш самостоятельный результат. Не нужно выдавать готовые проверки за собственную разработку.

## Выбор темы

На первом занятии — предварительная идея. До следующего занятия можно подумать неделю, выбрать своё или принести два варианта. Карточка: вопрос → доступные изображения → небольшой проверяемый результат → главная трудность. Преподаватель помогает ограничить объём. Лимита «два человека на трек» нет; интересны разные данные и вопросы.

| Направление | Посильная задача классификации |
|---|---|
| Дефекты | без дефекта / трещина / скол на фрагменте |
| Полка | место пусто / занято или несколько типов предметов |
| Документ | ориентация или тип страницы |
| Городская среда | тип знака на вырезанном фрагменте |
| Видео | тип объекта на фрагменте кадра |
| Своё | согласуем данные и 2–6 различимых классов |

Центральный эксперимент у всех один по принципу: классификация изображений/фрагментов, baseline на признаках (например HOG + линейный классификатор), затем небольшая CNN **на той же задаче и том же разбиении**. Сравниваем метрику, ошибки, затраты, а не только максимальное число. CNN не обязана победить. Подсчёт объектов, сканер документа, трекинг — упражнения курса или добровольные расширения; не заставляем каждого дополнительно решать детекцию.

## Этапы

| Когда | Что делаем | Результат |
|---|---|---|
| Блок 1 | предварительная идея и первый опыт | workbooks, README, копия |
| К блоку 2 | выбор темы; по возможности до 10 пробных кадров | карточка идеи, описание серий съёмки |
| Блоки 2–7 | собираем разнообразные данные небольшими порциями | изображения и журнал происхождения |
| Блоки 8–10, ЛР4 | фиксируем классы, разметку, группы train/validation/test | паспорт, воспроизводимый split |
| Блоки 9–11, ЛР5 | признаки + ML | метрики, ошибки, baseline |
| Блоки 10–12, ЛР6 | CNN и сравнение | кривые обучения, отчёт, защита |

Ориентир порядка 200 изображений обсуждаем после пробы, а не считаем магической гарантией качества. Кадры одного видео/серии и изображения одного объекта относятся к одной группе; не разносим почти одинаковые изображения между train и test. Все преобразования и аугментации учитывают split. Test не используем для подбора параметров. В документах разметки достаточно классификационных меток для своего проекта; рамки и маски изучаем на общих упражнениях, если они не нужны вашей задаче.

В «Нейронных сетях» пригодится опыт и, возможно, часть данных; новая задача может требовать новой разметки и другого набора. Продолжение на тех же данных не гарантируется.

## Репозиторий к защите

README: задача, данные, запуск, baseline и CNN на одной тестовой части, примеры ошибок, ограничения. Источники/условия использования — в datasheet.md. Сохраняйте небольшой разрешённый пример данных; большие или закрытые данные сопровождайте инструкцией получения. Оригиналы с телефона, лица, номера, ключи и личные сведения не публикуем автоматически. Публичное портфолио — опция после проверки.

Учебные задания в workbooks могут использовать course_support. Самостоятельный проект не должен зависеть от учебных checks; заимствованные функции оформляйте с указанием источника. Число коммитов не является мерой понимания. Оценивание — [ОЦЕНИВАНИЕ.md](ОЦЕНИВАНИЕ.md), перенос фото — [ДАННЫЕ.md](ДАННЫЕ.md).

Собственная съёмка полезна, но не обязательна: допустим согласованный набор с разрешённым использованием. Для учебных ЛР1–3 предоставляются общие данные, собственный телефон/EXIF не требуются.
