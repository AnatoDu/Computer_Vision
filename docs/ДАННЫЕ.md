# Как снимать данные для проекта

Для проекта можно снимать данные телефоном или использовать согласованный разрешённый набор; собственная съёмка не обязательна. Далее — инструкция для тех, кто выбрал съёмку. На занятиях они не нужны: там мы работаем с готовыми картинками курса. Снимать и переносить кадры — дома, в удобное время.

## Что снимать

- **Разнообразно.** Модель научится только тому, что видела. Снимайте днём и вечером, при разном освещении, с разных ракурсов и расстояний, на разном фоне.
- **Понемногу, но регулярно.** Если тема уже ясна — до 10 пробных кадров к занятию 2; иначе сначала карточка идеи. После пробы согласуем разнообразие и объём (ориентир около 200 изображений к блоку 8). Количество соседних кадров видео не заменяет независимые сцены.
- **Сериями.** Удобно снимать серию из 5–10 кадров одного объекта с разных сторон. Только помните: кадры одной серии очень похожи, и потом они должны попасть в одну часть датасета — об этом поговорим на занятии 9.
- **Видео** (необязательный источник фрагментов для классификации): ролики по 10–30 секунд, телефон неподвижно — прислоните его к окну или положите на подоконник. Горизонтально, 1080p или 720p.
- **Фото с iPhone.** По умолчанию iPhone сохраняет фото в формате HEIC. Либо включите в настройках камеры «Форматы → Наиболее совместимые» (тогда будет JPEG), либо установите пакет `pip install pillow-heif` — скрипт подготовки прочитает и HEIC.

## Чего не снимать

- **Лица людей крупным планом и номера машин.** Это могут быть персональные данные. Снимайте издалека, сверху или так, чтобы люди и номера не были главным в кадре. Если в кадр всё же попало лицо или номер — размойте их или не используйте кадр.
- **Документы с личными данными:** паспорт, СНИЛС, банковские карты — даже свои.
- **Там, где съёмка запрещена.** В магазине — только с разрешения администрации. Проще снять полки дома.

Для учебного проекта выбирайте объекты без идентифицирующих сведений. Не считайте съёмку в общественном месте автоматическим разрешением на публикацию; спорный набор сначала обсудите с преподавателем.

## Как перенести кадры на компьютер

Дома, любым удобным способом:
- кабелем;
- через облако (Яндекс Диск, Облако Mail);
- через Telegram: отправьте фото в «Избранное» **файлом**, а не как фото, и сохраните на компьютере.

Сложите файлы как есть в папку `cv_project/data/phone/`. Она не попадает в git: оригиналы большие, а ещё в них хранятся метаданные.

## Как подготовить кадры

В папке проекта выполните:

```bash
python tools/prepare_photos.py
```

Скрипт:
- поворачивает фото правильно (телефон часто хранит вертикальное фото горизонтальным, с пометкой «повернуть»);
- уменьшает фото до 1280 пикселей по длинной стороне: для начала; пригодность разрешения к выбранному дефекту/объекту проверяем отдельно;
- удаляет метаданные — модель телефона, время съёмки и **GPS-координаты места съёмки**;
- видео уменьшает до 480 пикселей по короткой стороне, обрезает до минуты и сохраняет без звука (в звуке могут быть чужие голоса);
- уже подготовленные файлы пропускает, так что запускать его можно после каждой съёмки.

Готовые кадры появятся в `data/raw/`. **Перед отправкой откройте их:** скрипт удаляет метаданные, но не лица, номера и текст в пикселях. Убедитесь, что использование и публикация разрешены. Только после этого отправляйте выбранные файлы:

```bash
git add data/raw
git commit -m "Новые кадры"
git push
```

Принесите копию своего проекта или скачайте его с GitHub: публичный доступен без входа, приватный требует авторизации. На общем компьютере не сохраняйте учётные данные. Пока аккаунта нет, обычная копия всей папки достаточна; Git bundle — необязательный перенос истории.

## Почему метаданные — это важно

Фото с телефона может содержать EXIF: модель телефона, дата и время, выдержка, ISO, а часто и координаты места съёмки с точностью до нескольких метров. Выложили в открытый репозиторий 200 фото из дома — выложили и адрес. Удаляйте метаданные всегда, когда публикуете фото, — не только в этом курсе. На занятии 2 мы посмотрим, что именно хранит EXIF.
